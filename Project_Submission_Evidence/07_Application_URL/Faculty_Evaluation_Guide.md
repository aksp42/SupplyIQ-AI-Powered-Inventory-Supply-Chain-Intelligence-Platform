# Faculty Evaluation Guide: Testing SupplyIQ

This evaluation guide provides professors, examiners, and project evaluation committees with structured testing pathways to verify the implementation, intelligence features, and system reliability of SupplyIQ.

---

## Evaluation Pathway 1: Instant Guest Demo Evaluation (Recommended)
**Purpose:** Rapid end-to-end evaluation with zero setup friction (no signup, no email verification, no OTP required).

1. **Launch the Demo Dashboard:**
   Open the following URL in any modern browser (Chrome, Edge, Firefox, Safari):
   ```
   https://supplyiq-9kmv.onrender.com/SupplyIQ-Grocery-Dashboard.html?demo=1
   ```
2. **Examine Core Modules (8 Navigation Tabs):**
   - **Dashboard Overview:** Observe dynamic KPI cards (Sales, Profit, Products Sold, Stock Received, Running Out of Stock) and hourly sales trends powered by Chart.js.
   - **Replenishment Tab:** Review automated Purchase Order recommendations generated by the dynamic Reorder Point (ROP) calculation.
   - **Products Catalog:** Test category filters (Dairy, Snacks, Grains, Personal Care), search bar SKU filtering, and product margin analysis.
   - **Inventory Levels:** Verify real-time stock balances, cover day metrics, and color-coded stock health tags (Healthy, Low Stock, Critical).
   - **Suppliers Tab:** Review vendor On-Time In-Full (OTIF) scores, lead times, and contact profiles.
   - **Risk & Alerts:** Inspect prioritized stockout warnings, impending product expirations, and overstock flags.
   - **Demand Forecast:** Inspect historical sales velocity projections and moving-average forecasts.
   - **Reports Tab:** Review store performance audit summaries and inventory valuation metrics.
3. **Test TradeSaarthi AI Assistant:**
   - In the dashboard, click on the **"Ask TradeSaarthi"** button or open the embedded chat widget.
   - Click any pre-configured prompt or type:
     - *"Which product will run out soon?"*
     - *"What should I order tomorrow?"*
     - *"How much profit did I make?"*
   - Observe contextual, data-backed responses generated directly from the active store ledger.

## Evaluation Pathway 2: Live User Registration & CSV Import
**Purpose:** Test end-to-end multi-tenant isolation, user authentication, and the chronological CSV validation engine.

1. **Sign Up for a New Store Account:**
   Navigate to [https://supplyiq-9kmv.onrender.com/public/signup.html](https://supplyiq-9kmv.onrender.com/public/signup.html) and create a test merchant account (e.g., `Test Kirana Store`).
2. **Sign In:**
   Log in at [https://supplyiq-9kmv.onrender.com/public/login.html](https://supplyiq-9kmv.onrender.com/public/login.html). You will be directed to your private store dashboard with a green **"• Live DB"** badge confirming connection to TiDB Cloud.
3. **Upload Stock Data:**
   - Scroll down to the **"Upload Stock Data"** drag-and-drop zone.
   - Upload any sample transaction CSV from `backend/csv/` or a custom sales ledger.
   - Inspect the **Import Preview Modal**:
     - SupplyIQ automatically verifies date formats, required columns, and sequence order.
     - Notice the intelligent auto-healing engine: if sales appear chronologically before receipts, SupplyIQ reorganizes them to prevent negative balance stock anomalies.
   - Click **Import Valid Rows** to commit transactions to the database.

## Evaluation Pathway 3: Backend API Health Probe
**Purpose:** Confirm backend runtime availability and database connectivity.

1. Execute in any terminal or browser:
   ```bash
   curl -i https://supplyiq-9kmv.onrender.com/api/health
   ```
2. Confirm the HTTP 200 OK status code and verified JSON payload:
   ```json
   {
     "status": "ok",
     "message": "SupplyIQ Backend (MySQL) running"
   }
   ```
